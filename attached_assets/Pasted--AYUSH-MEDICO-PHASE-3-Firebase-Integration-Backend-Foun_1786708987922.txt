# 2. FIREBASE WEB CONFIGURATION

The existing Firebase web application has already been configured.

Use the project's environment variables/secrets for Firebase configuration.

The configuration contains:

* API key
* Auth domain
* Project ID
* Storage bucket
* Messaging sender ID
* App ID
* Measurement ID
